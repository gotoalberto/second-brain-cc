## When

Publishing is an action taken on the user's behalf: it happens when the user asks for it in that exchange,
never on the agent's initiative, and a standing schedule the user removed takes its authorization with it.

## Where

Write down, as a convention note, which channel "publish it" means by default, and a directory of channel
ids. If the user names a channel whose id is not known, ask for it once and add it to the directory. Never
guess and never fall back to a channel that seems close.

## Shape of a post

- **The main channel message is a short title only.** The content, or the link, goes in the thread reply.
  Never dump a whole document or outline into the channel post.
- **Documents are shared as a link**, not attached or pasted: upload to the team's shared drive with
  access for the team, and put the link first in the thread reply, followed by two to five short bullets on
  what it contains and a line saying who can open it. Reuse an existing upload's link instead of creating a
  duplicate. Name the file so it reads well in a preview: topic, date, language.
- **Use the destination's own markup** (a chat tool's bold and bullet syntax is not markdown).
- **Language**: the channel's working language, whatever the conversation was in.
  [[2026-09-15-convention-language-per-audience]]
- **Posts under the user's name read like the user.** [[2026-09-10-convention-write-like-a-person]]

## Content taken from meetings

- Take the content from the meeting record the user named (the recording tool's outline or transcript) and
  nothing else. If it is not there, say so instead of reconstructing it from another source.
- Prefer the structured outline; use the full transcript only for an exact quote or who said what.
- Fix names the transcription got wrong when the reading is certain, leave them or generalize the sentence
  when it is not, and tell the user which names were corrected. Never print unidentified speaker labels as
  owners.
- Generated prose from other tools is full of dashes and filler: rewrite it, do not copy it through.

## Afterwards

Report the channel, the link and whether the post was verified. If the publishing path only confirms
receipt, say "submitted, not verified".
