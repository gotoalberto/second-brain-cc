## The rule

When the user has to choose, present the choice as a plain-text list in the chat message, never as an
interactive widget or component.

- Options lettered A, B, C, D, each with a one-line description.
- A final option that is always there: "Explain more", written in the user's language.
- If the user picks it: explain, then show the same list again.
- After the list, give your own recommendation with the reason.
- The user answers with the letter.
- One decision at a time; never stack several questions in the same turn.

## Why

Interactive decision widgets did not render on the user's phone, so the user saw nothing and could not
answer. A plain list works on every device and client, and a lettered answer is quick to type. One
decision at a time keeps each answer unambiguous.
