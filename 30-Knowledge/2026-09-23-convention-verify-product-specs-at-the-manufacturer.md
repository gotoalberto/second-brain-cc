## Rule

A web search answer block is not a source for a product spec. Before telling the user a product
has a feature, open the manufacturer's page, the manual, or the shop listing of that exact
model, and quote its wording back.

## Context

A device was recommended for a port it does not have. The search summary had merged several
models of the same family into one answer, and not all of them carry that port. The shop
listing did not mention the port at all. The same check later paid off the other way:
a vendor's own listing stated a limitation that no amount of reading summaries would have
settled.

## How to apply

When the user asks for a product with a specific port, switch or protocol:

1. Find candidates anywhere (shop search, web search).
2. Confirm the deciding feature on the vendor's own page, the manual, or the listing of that
   exact model, and quote it.
3. If no source states it, say the feature is unconfirmed instead of assuming it.
