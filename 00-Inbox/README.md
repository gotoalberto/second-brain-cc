# 00-Inbox

Quick, unsorted captures land here first — a stray idea, a link, a snippet, a half-formed note you don't want to lose. Drop it in without worrying about where it belongs.

Nothing lives here permanently. During triage, each capture is refined and moved to its proper home (for example a durable note in `30-Knowledge/`, a project update via `_bin/vw.py`, or an entity in `70-Entities/`), then removed from the inbox.

Keep it near empty: an inbox that never drains is just another pile.
